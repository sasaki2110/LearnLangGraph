LangGraph の学習、素晴らしいですね！
ただコードを動かすだけでなく、「なぜこのグラフ構造にするのか」を考えながら手を動かすのは、習得への一番の近道だと思います。

LangGraph の本質は **「状態（State）をどう定義し、ノード間でどう受け渡すか」** です。その理解を深めるための、ステップアップ形式のお題（15本ノック）を作成しました。

---

## 🟢 初級：グラフの基本構造（ノードとエッジ）

まずは「分岐」や「繰り返し」といった LangGraph の基本動作をマスターしましょう。

1. **挨拶エージェント**: 入力された言語（日本語/英語）を判定し、適切な言語で挨拶を返す（基本的な Conditional Edge の練習）。
2. **オウム返し＋文字数カウント**: 入力をそのまま返すノードと、文字数を数えて State に保存するノードを直列につなぐ。
3. **検閲エージェント**: LLM が回答を生成した後、別のノードが「不適切な言葉」がないかチェックし、あれば生成ノードに差し戻す（ループ構造の練習）。
4. **計算機ツールエージェント**: `add` や `multiply` などの自作関数をツールとして定義し、LLM が必要に応じてそれらを呼び出す（Basic Tool Use）。

---

## 🟡 中級：ステート管理と外部連携

State（状態）にリストを持たせたり、外部の情報を検索・記憶させたりする段階です。

5. **箇条書きまとめ屋**: 長い文章を、3つのノード（「重要点の抽出」「要約」「整形」）をリレーして短くする。
6. **Webリサーチアシスタント**: Tavily などの検索ツールを使い、調べた結果を State の `messages` リストに蓄積しながら最終回答を作る。
7. **TODO管理エージェント**: ユーザーの依頼から「タスク」「期限」を抽出し、State 内のリストを更新・削除する。
8. **人格の切り替え**: 「厳しい上司」と「優しい同僚」のノードを作り、入力内容に応じて適切な方にルーティングする。
9. **人間介在（Human-in-the-loop）**: ツールを実行する前に、一度実行を停止し、人間の承認を得てから再開する（`interrupt_before` の練習）。

---

## 🔴 上級：マルチエージェント・高度な制御

複数のエージェントが協力したり、複雑な並列処理を行う段階です。

10. **ライター＆校閲者**: 記事を書く「Writer」と、それを添削する「Editor」が、合格点が出るまで無限ループ（または最大n回）やり取りする。
11. **並列リサーチ**: 1つのトピックに対し、3つの異なる視点から同時に検索を行い（Parallel node execution）、最後に1つのレポートにまとめる。
12. **長期記憶エージェント**: Checkpointer を使い、スレッドIDを指定することで前回の会話内容を保持・再開する。
13. **カスタマーサポート・オーケストレーター**: ユーザーの質問を分析し、「技術担当」「請求担当」の専門エージェントにタスクを振り分け、最後に回答を統合する。
14. **セルフリフレクション (Self-Reflection)**: 生成した回答を自分で批判させ、改善点をリストアップしてから最終回答を再生成する。
15. **Map-Reduce エージェント**: 大量のドキュメントを分割して並列処理し、最後に集約（Reduce）して全体像を把握する。

### 学習のコツ

* **State の設計から入る**: プログラムを書く前に「このグラフは何を覚えている必要があるか（State の定義）」を紙に書き出してみてください。
* **可視化する**: `display(Image(app.get_graph().draw_mermaid_png()))` を毎回実行して、自分の意図通りに線がつながっているか確認しましょう。
